# Тренажер для вступительных испытаний (БГУ)

Минималистичное интерактивное веб-приложение (SPA) для подготовки к вступительным экзаменам. Работает полностью на стороне клиента, не требует настройки сервера и сохраняет весь прогресс локально.

## 🚀 Особенности

* **Обширная база**: 350 вопросов по трём дисциплинам («Основы инж.-тех. наук», «Русский язык», «Прикладная физика»).
* **Защита от потери данных**: Автоматическое сохранение прогресса, баллов и выбранных ответов в `localStorage`. При случайном закрытии вкладки тест продолжится с того же места.
* **Интерактивный фидбек**: Цветовая индикация правильности ответа и подробные объяснения с цитированием учебных программ после каждого вопроса.
* **Удобная навигация**: Выдвигающееся боковое меню (Drawer) для быстрого перехода к любому вопросу.
* **Адаптивный дизайн**: Корректное отображение на любых устройствах от смартфонов до десктопов.

## 🛠 Стек технологий

* **HTML5**
* **Tailwind CSS** (via CDN)
* **Vanilla JavaScript** 

## 📦 Запуск проекта

Проект не требует сборки. Для запуска достаточно склонировать репозиторий и открыть файл `index.html` в любом современном браузере.
